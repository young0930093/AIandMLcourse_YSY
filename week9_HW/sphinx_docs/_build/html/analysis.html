분석¶

Euler 방법은 1차 정확도(오차 비례 delta_t)로, 시간이 지날수록 오차가 폭발적으로 누적된다. 특히 단진자처럼 에너지가 보존되어야 하는 시스템에서 에너지가 계속 증가해 결국 발산한다.

RK4는 4차 정확도(오차 비례 delta_t^4)로, 동일한 시간 간격에서 Euler보다 수백억 배 정확하다. 4배의 계산 비용이 들지만 실용적인 수치 시뮬레이션에서는 RK4를 사용해야 한다.

핵심: RK4가 Euler보다 약 2.8 x 10^28 배 더 정확함

분석¶

뉴턴의 만유인력 법칙(F = -GMm/r^2)을 RK4로 수치 적분한 결과, 케플러의 세 가지 법칙이 모두 정확하게 재현되었다.

  • 제1법칙: 시뮬레이션된 궤도가 타원을 그림 (이심률 e = 0.0167 for 지구)

  • 제2법칙: 각운동량 보존 → 근일점에서 빠르게, 원일점에서 느리게 이동

  • 제3법칙: T^2/a^3 ≈ 1.000 으로 정밀하게 성립

에너지와 각운동량이 0.0001% 미만으로 보존되어, RK4의 우수한 보존 성능을 확인했다.

분석¶

초기 조건이 0.001도(0.00001745 rad)밖에 차이 나지 않는 두 이중 진자가 약 15.59초 후 완전히 다른 운동을 보였다. 이것이 **나비 효과(Butterfly Effect)**의 핵심이다.

리아푸노프 지수 lambda ≈ 0.556 s^-1 이 양수라는 것은 시스템이 혼돈적임을 수학적으로 증명한다. 두 궤적의 차이는 delta(t) = delta_0 * e^(lambda*t) 로 지수적으로 증가하며, 예측 가능 시간은 1/lambda ≈ 1.8초에 불과하다.

핵심: 결정론적(방정식이 명확)이지만 장기 예측이 불가능한 것이 혼돈 시스템의 본질이다.

분석¶

2체 문제와 달리 3체 문제는 일반적으로 해석해가 존재하지 않아 수치 시뮬레이션이 필수다.

  • Figure-8 궤도: 세 동일 질량 천체가 8자 형태의 안정 궤도를 공유하는 특수해. 에너지와 운동량이 기계 정밀도(1e-14) 수준으로 보존됨

  • 태양-지구-달: 실제 질량비(태양:지구:달 = 1 : 3e-6 : 3.7e-8)를 사용. 달이 지구 주위를 정상적으로 공전

  • 라그랑주 L4: 작은 천체(m = 0.001)가 두 큰 천체로 이루어진 정삼각형 꼭짓점에 위치하는 안정 배치

질량중심 좌표계 변환을 통해 운동량이 정확히 0으로 보존되는 것을 확인했다.

분석¶

  • 행렬 곱셈: 규모가 커질수록 가속비가 급증. 200x200에서 2,290배 빠름. NumPy는 C로 구현된 BLAS 라이브러리를 사용해 SIMD 명령어로 병렬 연산을 수행하기 때문

  • 거리 계산: 소규모(n=10)에서는 NumPy overhead로 오히려 느림. n이 커지면 브로드캐스팅의 이점이 나타남

  • 필터링: 동일한 O(n) 복잡도로 가속비가 크지 않음. 단, 코드 가독성은 NumPy 버전이 훨씬 좋음

핵심 교훈:

  1. Python 루프는 피하고 NumPy 벡터화 연산을 사용할 것

  2. 최적화 효과는 데이터 규모에 따라 달라짐 — 작은 데이터엔 overhead가 클 수 있음

  3. 프로파일링 후 병목 지점을 찾아 최적화할 것
