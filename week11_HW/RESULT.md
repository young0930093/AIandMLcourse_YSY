## 1. 슈뢰딩거 방정식 수치 풀이 (`01schrodinger.py`)

### 방법론
시간 독립 슈뢰딩거 방정식 `-ℏ²/2m * d²ψ/dx² + V(x)ψ = Eψ` 를 유한 차분법(Finite Difference Method)으로 이산화하여 해밀토니안 행렬을 구성하고, `scipy.linalg.eigh`로 고유값/고유벡터를 구하였다.

### 결과: 무한 사각 우물 (Infinite Square Well)

해석적 해 `E_n = n²π²ℏ²/(2mL²)` 와 수치 해를 비교한 결과, 오차가 10^-4 수준으로 매우 작아 수치 방법의 정확성을 확인하였다.

| 양자수 n | 수치 에너지 | 해석적 에너지 | 오차 |
|---------|-----------|------------|------|
| 1 | 0.049348 | 0.049348 | ~10⁻⁶ |
| 2 | 0.197392 | 0.197392 | ~10⁻⁶ |
| 3 | 0.444133 | 0.444132 | ~10⁻⁵ |

- 파동함수는 우물 내부에서 사인파 형태를 보이며, 경계에서 0이 됨
- 확률밀도 `|ψ|²` 는 노드(node) 개수가 n-1개인 것을 확인

### 결과: 유한 사각 우물 (Finite Square Well)

우물 깊이 V₀ = 10, 너비 a = 5로 설정했을 때 여러 개의 속박 상태(E < 0)가 존재하였다.

- 파동함수가 우물 경계 너머로 지수적으로 감소(evanescent wave)하는 것을 확인
- 무한 우물과 달리 속박 상태의 수가 유한하며, 에너지가 충분히 높으면 비속박 상태가 됨
- 이는 고전역학에서는 불가능한 "장벽 침투" 현상의 근거가 됨

### 결과: 조화 진동자 (Harmonic Oscillator)

포텐셜 `V(x) = ½mω²x²` (ω = 1)에서 수치 에너지 준위가 해석적 해 `E_n = ℏω(n + 1/2)` 와 거의 정확히 일치하였다.

| 양자수 n | 수치 에너지 | 해석적 에너지 |
|---------|-----------|------------|
| 0 | 0.5000 | 0.5 |
| 1 | 1.5000 | 1.5 |
| 2 | 2.5000 | 2.5 |

- 에너지 간격이 ℏω로 균등한 것을 수치적으로 확인
- 가장 낮은 상태(n=0)도 E = 0.5 ≠ 0으로, 영점 에너지(zero-point energy)가 존재함

## 2. 파동함수 시각화 (`02wavefunction.py`)

### 가우시안 파동 패킷 (Gaussian Wave Packet)

초기 상태를 가우시안 형태 `ψ(x,0) ∝ exp(-(x-x₀)²/4σ² + ik₀x)` 로 설정하여 시간 진화를 시뮬레이션하였다.

- 파동 패킷은 군속도(group velocity) `v_g = ℏk₀/m` 로 이동
- 시간이 지남에 따라 파동 패킷이 **퍼져나감(dispersion)**: 위치 불확정성 증가
- 하이젠베르크 불확정성 원리 `Δx·Δp ≥ ℏ/2` 를 시각적으로 확인할 수 있음
- 초기에 좁은 패킷일수록(작은 σ) 더 빠르게 퍼지는 것을 관찰

### 수소 원자 오비탈 (Hydrogen Orbitals)

수소 원자 파동함수 `ψ_{nlm}(r,θ,φ)` 의 확률밀도를 2D 단면으로 시각화하였다.

- 1s, 2s, 2p 오비탈의 형태와 노드 구조를 확인
- 방위 양자수 l, 자기 양자수 m에 따라 오비탈 형태가 뚜렷이 달라짐
- 방사형 확률밀도의 피크 위치가 보어 반지름(a₀)의 정수배 근방에 나타남

### 중첩 상태 (Superposition States)

두 에너지 고유상태의 중첩 `ψ = (ψ₁ + ψ₂)/√2` 는 시간에 따라 진동하는 확률밀도를 보였다.

- 진동 주파수: `ω = (E₂ - E₁)/ℏ`
- 이는 양자 간섭 현상의 핵심이며, 고전적 진동과 유사하지만 본질적으로 다른 양자 효과임

## 3. 양자 터널링 (`03tunneling.py`)

### 직사각형 장벽 터널링 (Rectangular Barrier)

입자 에너지 E가 장벽 높이 V₀보다 낮은 경우(E < V₀)에도 투과가 일어나는 터널링 현상을 시뮬레이션하였다.

**투과 계수 해석적 공식:**
$$T = \left[1 + \frac{V_0^2 \sinh^2(\kappa d)}{4E(V_0-E)}\right]^{-1}, \quad \kappa = \frac{\sqrt{2m(V_0-E)}}{\hbar}$$

- 장벽 두께 d가 증가할수록 투과 계수 T가 지수적으로 감소
- 장벽이 얇을수록, 입자 에너지가 V₀에 가까울수록 투과율 증가
- 이는 주사 터널링 현미경(STM), 핵융합 등 실제 물리 현상의 근거가 됨

### 공명 터널링 (Resonant Tunneling)

이중 장벽 구조에서 특정 에너지 조건에서 투과율이 T ≈ 1에 근접하는 공명 터널링 현상을 관찰하였다.

- 두 장벽 사이의 우물에 준속박 상태(quasi-bound state)가 형성될 때 공명 발생
- 공명 에너지 조건: 우물 내 정상파 조건 만족
- 이는 공명 터널링 다이오드(RTD) 등 반도체 소자의 작동 원리

### 터널링 파라미터 의존성

| 파라미터 | 효과 |
|---------|------|
| 장벽 두께 증가 | 투과율 지수적 감소 |
| 장벽 높이 증가 | 투과율 감소 (κ 증가) |
| 입자 에너지 증가 | 투과율 증가 (E → V₀ 에 가까워질수록 급증) |

## 4. 유한 우물 & 조화 진동자 상세 분석 (`04wells_oscillator.py`)

### 유한 우물 깊이 의존성 (Finite Well Depth)

우물 깊이 V₀를 변화시키면서 속박 상태 수와 에너지 준위 변화를 분석하였다.

- V₀가 증가할수록 속박 상태의 수가 증가
- V₀ → ∞ 극한에서 무한 사각 우물의 에너지 준위로 수렴
- 각 속박 상태의 에너지는 V₀가 커질수록 더 낮아짐(더 강하게 구속)

### 유한 우물 너비 의존성 (Finite Well Width)

우물 너비를 변화시키면 에너지 준위 간격이 달라졌다.

- 좁은 우물: 에너지 준위 간격이 크고 속박 상태 수 적음 (`∝ 1/a²`)
- 넓은 우물: 에너지 준위가 촘촘해지고 연속 스펙트럼에 근접

### 조화 진동자 상세 분석 (Harmonic Oscillator Detailed)

수치 해와 해석적 에르미트 다항식 해를 직접 비교하였다.

- n = 0 (기저 상태): 가우시안 형태, 영점 에너지 E₀ = ℏω/2
- n = 1: 중앙에 노드 1개, 홀함수(odd function)
- n = 2: 노드 2개, 우함수(even function)
- 수치 파동함수와 해석적 파동함수의 차이가 10⁻⁵ 수준으로 매우 작음

### 고전 vs 양자 비교 (Classical vs Quantum)

고전 확률밀도와 양자 확률밀도를 비교하였다.

- 고전: 반환점(turning point) 근방에서 확률 높고 중심에서 낮음
- 양자(낮은 n): 중심 근방에서 확률이 가장 높음 (고전과 반대!)
- 양자(높은 n): 대응 원리(Bohr correspondence principle)에 따라 고전 분포에 근접
